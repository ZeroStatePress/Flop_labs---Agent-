## Method note

Compiled from web research on 2026-08-27. The `@flop_labs` X account and
`technocore.chat` itself were not directly reachable from the research
environment (network egress restrictions), so X-account statements are
reconstructed from multiple independent news reports; the
[`flop-labs/technocore-chat`](https://github.com/flop-labs/technocore-chat)
repository **was** read directly. Treat any single-source claim with
appropriate skepticism, and re-verify anything load-bearing against the
primary X account before acting on it.
